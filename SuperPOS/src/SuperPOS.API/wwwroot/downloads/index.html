SuperPOS - Descargas

Cliente de caja (Windows / WPF)

Se conecta directo a la API en este servidor.

Descargar SuperPOS-Client-win-x64.zip

Requisito: esta build necesita el .NET 10 Desktop Runtime (x64) instalado en la PC. Si no lo tenés, descargalo primero desde dotnet.microsoft.com (elegir "Desktop Runtime x64").

Pasos: instalar el runtime (si hace falta) → descomprimir el zip → ejecutar SuperPOS.Client.exe.

App móvil (Android / colectoras)

Para escaneo de código de barras, ingreso de stock y etiquetas desde colectoras Zebra o celulares Android.

Descargar SuperPOS-Mobile.apk

Firmado con certificado propio (no viene de Google Play). Al instalar, Android va a advertir "origen desconocido" — hay que permitirlo explícitamente en el instalador.

Compatible con Android 8.1 (API 26) o superior.
